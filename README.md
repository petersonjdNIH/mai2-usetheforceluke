# Use the Force, Luke

An interactive, procedural visual demo of Luke Skywalker's trench run, built
with plain HTML, CSS, Canvas, and Web Audio. No build step or dependencies are
required.

## Run

Open `index.html` directly, or serve the directory locally:

```sh
python3 -m http.server 4173
```

Then visit <http://localhost:4173>.

## Controls

- Move the pointer or use the arrow keys to steer.
- Press `F` or click the torpedo control when target lock is ready.
- Press Space to pause or resume.
- Select any numbered chapter to jump to that phase.

The audio toggle enables synthesized cockpit ambience and effects. The visual
experience remains fully usable without audio.
